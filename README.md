```markdown
# こもれび堂　月次売上レポート作成ツール

毎月の受注CSVから、売上レポート（Excel）を自動で作るツールです。

---

## 毎月の使い方（3ステップ）

### 1. 受注CSVをダウンロードする

ネットショップの管理画面から、その月の受注データをCSVでダウンロードします。

### 2. ファイル名を変えて、input フォルダに入れる

ファイル名を **`orders_年月.csv`** に変えます。年は4けた、月は2けたです。

| 月 | ファイル名 |
|---|---|
| 2026年11月 | `orders_202611.csv` |
| 2026年12月 | `orders_202612.csv` |
| 2027年1月 | `orders_202701.csv` |

名前を変えたら、**`input`** フォルダに入れます。

### 3. run.bat をダブルクリックする

黒い画面が開いて、自動で処理が進みます。
**【完了】** と表示されると、**`report`** フォルダが開きます。
その中の **`売上レポート_2026年11月.xlsx`** がレポートです。

黒い画面は、何かキーを押すと閉じます。

---

## 「確認が必要な注文があります」と表示されたら

金額の計算が合わない注文が見つかったという意味です。

1. レポートの **「修正ログ」** シートを開きます。
2. **【要確認】** と書かれた行の注文番号をメモします。
3. 担当者に連絡してください。

確認が終わったら、担当者が修正リストを作ります。そのあと、もう一度 `run.bat` をダブルクリックすると、正しいレポートができます。

---

## 「エラー」と表示されたら

黒い画面を **閉じずに**、画面を撮影（スクリーンショット）して、担当者に送ってください。

---

## やってはいけないこと

- `input` フォルダのCSVを、**Excelで開いて上書き保存しない**（商品コードの先頭の0が消えます）
- `.py` で終わるファイルや、`.venv` フォルダを **さわらない**

---

## フォルダの中身

| 名前 | 中身 | さわる？ |
|---|---|---|
| `input` | 受注CSV・修正リストを置く場所 | ✅ CSVを入れる |
| `report` | できあがったレポート | ✅ 開いて見る |
| `run.bat` | ダブルクリックで実行する | ✅ ダブルクリック |
| `output` | 途中のデータ | ❌ |
| それ以外 | プログラム本体 | ❌ |

---

## 担当者向けメモ

- 初回のみ：`python -m venv .venv` → `.venv\Scripts\pip install -r requirements.txt`
- 処理の流れ：`run.py` → `03_clean.py`（検品・修正・除外）→ `04_report.py`（集計・Excel出力）
- 個別の修正は `input/corrections_YYYYMM.csv`（列：注文番号, 商品コード, 列, 正しい値, 理由）
- `input/` `output/` `report/` は顧客データのため Git 管理外
```
